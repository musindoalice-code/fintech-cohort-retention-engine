# The Automated Fintech Cohort & Revenue Retention Engine

## 📊 Executive Summary
In the high-growth Fintech and SaaS landscapes, traditional backward-looking accounting fails to answer a foundational question: *Are our acquired customers retaining value over time?* This project builds a production-grade data pipeline that calculates **Net Revenue Retention (NRR)** and **Customer Cohort Churn** directly from raw ledger transactions. 

By bypassing slow IT ticketing cycles, this engine bridges the gap between deep data engineering and real-time executive capital deployment strategies.

## 🛠️ Tech Stack & Architecture
* **Data Processing:** Python (Pandas, NumPy) & Databricks (PySpark scalable logic)
* **Storage & Versioning:** Git / GitHub
* **Visualization:** PowerBI Desktop & Lovable dynamic user-interface configuration

### Data Pipeline Architecture:
[Raw Production Ledger] ──> [Python Cleansing & Cohort Grouping] ──> [Dynamic Matrix Output] ──> [Lovable Dashboard Delivery]

## 📈 Key Strategic Metrics Calculated
1. **Gross Revenue Retention (GRR):** Tracks core customer base loyalty excluding expansion.
2. **Net Revenue Retention (NRR):** Factors in upgrades, cross-sells, and downgrades. (The ultimate health metric for tech investors).
3. **Monthly Churn Velocity:** Identifies structural platform abandonment timeline drops.

## 💡 Strategic Business Value Delivered
* **Investor Pitch Readiness:** Provides a bulletproof, real-time cohort matrix formatted directly for Venture Capital (VC) Due Diligence rounds.
* **Early Warning Churn Identification:** Detects sudden retention drops at Month 3 or Month 6, giving marketing teams the margin window to deploy targeted customer win-back initiatives before cash runway degradation occurs.
